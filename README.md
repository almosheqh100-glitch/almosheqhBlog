# almosheqhBlog

> يجري تجهيز الإصدار 1.4.0. آخر إصدار منشور حاليًا هو 1.3.0؛ ربط إرسال الإشعارات عند النشر لم يكتمل بعد.

## ميزات 1.4.0 قيد التجهيز

- مفضلة وقسم مستقل للمقالات المنزلة، وحفظ النص والصور المتاحة مع بيان عدد الصور المحفوظة. لا تحفظ ملفات الفيديو أو المحتوى الخارجي؛ الصور الكبيرة أو المتعذرة تظهر بعلامة واضحة.
- تكبير الخط وتصغيره والوضع الليلي داخل القارئ، مع حفظ الإعدادات.
- حفظ آخر مقال وموضع القراءة على الهاتف، وزر متابعة القراءة.
- ترتيب جميع المقالات حسب إجمالي المشاهدات؛ المقالات ذات الأعداد غير المتاحة تأتي أخيرًا.
- رجوع داخل المقال، ومشاركة واتساب وفيسبوك وX وإنستجرام. إنستجرام قد لا يقبل النص مباشرة؛ يُنسخ الرابط لتلصقه عند الحاجة.
- إعلان الحالة لقارئ الشاشة وإعادة التركيز إلى زر المقال عند الرجوع وتعريب «حول التطبيق».
- استقبال Firebase Cloud Messaging مستقل عن تشغيل واجهة Python. يحتاج خدمة إرسال موصولة بـWordPress Webhook قبل تفعيله فعليًا، مع السماح بالإشعارات وخدمات Google Play. لا يتضمن مفتاح إرسال خاصًا داخل APK.

للبناء من المصدر أضف `python scripts/install_android.py` بعد إنشاء مشروع أندرويد وقبل البناء، لنسخ خدمة Firebase وموارد إعداداتها. ملف `android/google-services.json` يحتوي إعداد عميل Firebase؛ لا تضع مفاتيح حساب خدمة أو أسرار خادم في المستودع.

تطبيق أندرويد لمدونة عبدالرحمن المشيقح — الإصدار 1.3.0.

## التنزيل

نزّل ملف **almosheqhBlog-1.3.0.apk** من [صفحة الإصدارات](https://github.com/almosheqh100-glitch/almosheqhBlog/releases).
الإصدار النهائي هو Release APK موقّع بمفتاح إصدار، وليس مفتاح Debug.
إذا ثبّتَّ النسخة التجريبية السابقة، احذفها أولًا بسبب اختلاف التوقيع، ثم ثبّت النسخة الجديدة.
الإصدار متاح للتثبيت المباشر؛ لم يُنشر في Google Play.
يمكن تثبيت 1.3.0 كتحديث فوق الإصدار الرسمي 1.1.0 أو 1.2.0 دون حذفه، إذ يستخدم المفتاح نفسه.

## فتح المقال والتحديثات

يفتح المقال داخل الشاشة الرئيسية، مع زر للعودة إلى القائمة المحفوظة، لمعالجة عدم دعم النوافذ الإضافية على أندرويد. لا ينتظر تحميل قائمة المقالات اكتمال تحديث المشاهدات.

يتحقق التطبيق تلقائيًا من أحدث إصدار رسمي عند تشغيله أو عودته إلى الواجهة، ويوفر زرًا للتحقق يدويًا. عند توفر إصدار أحدث يظهر زر لعرض وصفه. تعرض صفحة التحديث وصف الإصدار ثم زر «تنزيل التحديث مباشرة»؛ لا يبدأ التنزيل بمجرد الفحص.

على Android 10 فأحدث، يرسل الزر ملف APK إلى مدير التنزيلات في الهاتف، ويمكن فتح الملف بعد اكتماله من إشعار التنزيل. على الإصدارات الأقدم أو عند تعذر مدير التنزيلات يفتح رابط APK المباشر في المتصفح. يؤكد المستخدم تثبيت التحديث من أندرويد؛ لا يوجد تثبيت صامت.

عند نشر كل إصدار، اكتب وصف التغييرات في GitHub Release، واستخدم وسمًا مثل `v1.4.0` وأرفق APK موقعًا باسم `almosheqhBlog-1.4.0.apk`. لا يعرض التطبيق إصدارًا تجريبيًا أو مسودة، أو إصدارًا بلا وصف أو ملف APK. ارفع رقم الإصدار في `pyproject.toml` و`updates.py` واستخدم مفتاح التوقيع نفسه. نشر المسودة بعد رفع الملف يمنع عرض إصدار غير مكتمل.

## مشاهدات المقالات

يعرض زر كل مقال إجمالي مشاهداته على المدونة قبل فتحه، ضمن النص الذي يقرؤه قارئ الشاشة عند التركيز عليه. العدد مستمد من إحصاءات WordPress لجميع الأوقات، وليس عدد فتحات التطبيق.

يجلب التطبيق أحدث نسخة للأعداد عند فتح قائمة المقالات أو البحث. ينفّذ GitHub Actions المزامنة كل ساعة تقريبًا (قد يتأخر تشغيله)، ويظهر وقت آخر تحديث في القائمة. إذا تعذر الاتصال يحتفظ التطبيق بالأعداد المحفوظة وتاريخها؛ وإذا لم يتوفر عدد لمقال، يعرض «عدد المشاهدات غير متاح» بدل صفر وهمي.

يحفظ `WP_STATS_TOKEN` في GitHub Secrets بصلاحية `stats` فقط للمدونة. تنشر المزامنة إجمالي عدد المشاهدات لكل مقال منشور في `views.json` على فرع `stats`، دون بيانات الزوار أو رموز الربط. لا يحتوي التطبيق على أي رمز وصول إلى الحساب.

```sh

briefcase build android --no-input
briefcase package android -p apk --no-input
```
